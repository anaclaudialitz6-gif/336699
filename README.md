# 336699 — painel demonstrativo

Interface responsiva em HTML, CSS e JavaScript puro.

## Arquivos
- `index.html`: painel inicial.
- `perfil.html`: edição do perfil demonstrativo.
- `style.css`: estilos e layout.
- `script.js`: navegação e salvamento local do perfil.
- `assets/`: pasta reservada para imagens e ícones.

## Como publicar no GitHub Pages
1. Crie ou abra um repositório no GitHub.
2. Envie todos os arquivos mantendo a estrutura de pastas.
3. Abra **Settings → Pages**.
4. Em **Build and deployment**, escolha **Deploy from a branch**.
5. Selecione a branch `main` e a pasta `/ (root)`, depois salve.
6. Aguarde o GitHub mostrar o endereço público do site.

## Observação
Este é somente um protótipo visual/demonstrativo. Não possui autenticação real, banco de dados, depósitos, saques, pagamentos ou apostas. Os dados de perfil ficam apenas no armazenamento local do navegador e não devem ser usados para informações sensíveis.
